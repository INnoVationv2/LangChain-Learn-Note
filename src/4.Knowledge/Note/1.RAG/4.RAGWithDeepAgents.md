# 基于DeepAgent的检索增强生成(RAG)

目标: 一个文档问答Agent：为 [docs.langchain.com](https://docs.langchain.com/) 中的部分文档建立索引, 在用户提问时检索相关片段, 将其保存到文件系统, 再交给SubAgent分析, 避免主Agent的上下文被大量文档内容占满.

## RAG 模式

Deep Agents 支持以下几种方式来组织检索、分析和答案生成：

- **按Skill指引检索**：用户提问后, Agent加载相关Skill, 了解该用哪个索引、如何编写查询、如何标注引用, 再按照指引调用检索Tool, 整理资料并回答.
- **按评分标准检查答案**：Agent先检索资料并起草答案, 再由配置了`RubricMiddleware`的评分SubAgent检查答案是否有资料依据.Agent根据检查结果修改答案, 直到通过检查或达到迭代次数上限.
- **按待办清单逐项查找**：启用任务规划后, Agent会先列出需要查看的文档页面或需要搜索的问题, 再逐项检索, 最后根据收集到的资料回答.
- **检索、存入文件、交给SubAgent处理**：Agent检索相关文档片段, 将它们写入文件系统, 避免大量原文占用主Agent的上下文.多个SubAgent可以并行读取、搜索和总结不同文件.对于大型文档, Agent可以使用内置搜索Tool分段查看, 也可以运行代码解释器, 根据原始数据生成表格、时间线或图表.

本教程采用最后一种模式：**检索、存入文件、交给SubAgent处理**.

这些能力也可以组合使用：Skill可以封装检索流程, 评分标准可以检查上述任意流程的结果, 任务规划则能把复杂问题拆成几个更具体的搜索任务.

## 将构建的功能

1. **建立索引**：索引LangChain文档, 将文档加载到向量数据库中.
2. **搜索资料**：创建自定义Tool, 通过向量相似度搜索找到相关文档片段, 并将每个片段保存到Agent的文件系统.
3. **分析资料**：让SubAgent读取文件, 提炼与问题相关的内容.
4. **生成答案**：由主Agent汇总SubAgent的分析结果, 给出最终答案.

## 1.建立索引

建立索引时, 先将原文切成小片段, 再转换为表示其语义的数值向量.将向量与对应的文档片段一起存入`VectorStore`, 就能在用户提问时, 把问题也转换成向量, 快速找到含义相近的内容.

建立索引通常分为四步：

1. **加载**：将数据源加载为`Document`对象.
2. **切分**：使用文本切分器, 将较大的文档拆成小片段, 方便检索和传给模型.片段过大不仅难以检索, 还可能超出模型的上下文窗口, 消耗不必要的 token.
3. **向量化**：使用Embeddings模型, 将每个片段转换成表示其含义的数值向量, 用于相似度搜索.
4. **存储**：将文档片段及其向量存入`VectorStore`, 供检索.

LangChain 提供 Markdown 格式的文档, 地址为：

```
https://docs.langchain.com/{path}.md
```

本教程只挑选部分文档建立索引, 想让Agent能查到更多文档, 有两种方式：

- 扩充`DOC_PATHS`：在代码的文档路径列表里, 手动添加更多页面.
- 读取`llms.txt`：从网站提供的文档目录文件中提取页面地址, 再加载这些页面、建立索引.

只有被加载并建立索引的文档, 才能被这个检索Tool查到.

## 2.添加检索Tool

`search_documentation`Tool对向量文档库进行相似度搜索, 将检索到的文本块写入`backend`的`/retrieved/{batch_id}/`目录.之后返回文件路径, 让主Agent可以委派分析任务, 无需将完整文本块加载到自己的上下文中.

```ts
const searchDocumentation = tool(
    async ({query}) => {
        const retrievedDocs = await vectorStore.similaritySearch(query, 4);
        const batchId = uuid7().slice(0, 8);
        const uploads: Array<[string, Uint8Array]> = [];
        const savedPaths: string[] = [];
        const encoder = new TextEncoder();

        retrievedDocs.forEach((doc, index) => {
            const path = `/retrieved/${batchId}/chunk_${index + 1}.md`;
            const content = `# Source: ${doc.metadata.source ?? "unknown"}\n\n${doc.pageContent}`;
            uploads.push([path, encoder.encode(content)]);
            savedPaths.push(path);
        });

        backend.uploadFiles(uploads);
        return `Saved ${savedPaths.length} documentation chunks:\n${savedPaths.join("\n")}`;
    },
    {
        name: "search_documentation",
        description:
            "Search LangChain documentation and save matching chunks to the agent filesystem.",
        schema: z.object({
            query: z.string().describe("Natural language search query."),
        }),
    },
);
```
