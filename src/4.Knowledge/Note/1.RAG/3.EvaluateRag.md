# 评估 RAG 应用

评估流程分为三步：

1. **创建数据集**：准备问题和预期答案.
2. **运行应用**：让 RAG 应用回答这些问题.
3. **评价结果**：使用评估器衡量回答的相关性、准确性和检索质量.

本教程将构建并评估一个问答机器人, 回答有关Lilian Weng几篇博客文章的问题.

**测试四个方面**

让大模型充当评审, 比较问题、RAG答案、标准答案和检索文档.

1. 正确性`(correctness)`

   - 输入: 问题, 参考答案和RAG答案

   - 目标: 评估RAG答案与标准答案的相符程度

2. 相关性`(relevance)`

   - 输入: 问题和RAG答案

   - 目标: 评估RAG答案是否充分回答了问题

3. 依据性`(Groundedness)`

   - 输入: RAG答案和检索结果

   - 目标: 评估RAG答案是否忠于检索结果, 是否存在幻觉

4. 检索相关性`(Retrieval relevance)`

   - 输入: 问题和检索结果

   - 目标: 评估问题和检索结果的相关性
