# 评估 RAG 应用

本教程介绍如何使用 **LangSmith 评估RAG应用**, 评估流程分为三步：

1. **创建数据集**：准备问题和预期答案。
2. **运行应用**：让 RAG 应用回答这些问题。
3. **评价结果**：使用评估器衡量回答的相关性、准确性和检索质量。

本教程将构建并评估一个问答机器人，回答有关Lilian Weng几篇博客文章的问题。

主要评估三个方面：

| 评估方面   | 检查什么                     |
| ---------- | ---------------------------- |
| 回答相关性 | 回答是否切合问题             |
| 回答准确性 | 回答内容是否正确             |
| 检索质量   | 是否找到了回答问题所需的资料 |

使用LangSmith进行评估并记录结果，帮助发现问题出在哪个检索环节。
