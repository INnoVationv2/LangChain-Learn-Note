# 语义检索(semantic search)

1. 从PDF创建文档对象。
2. 生成嵌入向量。
3. 加载并分割PDF文件。
4. 在向量存储中建立索引块，并按相似度进行查询。
5. 把商店包装成一只寻回犬。

## 1.创建文档

LangChain实现了文档抽象。具有三个属性：

```
- pageContent: 内容字符串
- metadata: 包含元数据
- id: (可选)文档的字符串标识符。
```

metadata记录文档的来源、与其他文档的关系和其他信息。

单个Document通常是大文档的一部分。

## 2.生成嵌入

把文本转换成数字向量，通过比较向量的相似度，找到与问题语义相关的文本。

过程如下：

1. **存储**：把文本转换成向量，并保存文本与向量的对应关系。
2. **搜索**：把问题也转换成相同维度的向量。
3. **比较**：用余弦相似度等方法，找出最相似的向量，返回对应文本。
