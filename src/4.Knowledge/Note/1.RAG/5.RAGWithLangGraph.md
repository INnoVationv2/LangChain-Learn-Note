# 使用 LangGraph 构建自定义 RAG Agent

使用 LangGraph 构建一个检索Agent, 让它决定何时搜索向量存储、何时直接回答用户.

## 总体流程

```ts
const graph = new StateGraph(State)
    .addNode('generateQueryOrRespond', generateQueryOrRespond)
    .addNode('retrieve', toolNode)
    .addNode('gradeDocuments', gradeDocuments)
    .addNode("rewrite", rewrite)
    .addNode("generate", generate)
    .addEdge(START, "generateQueryOrRespond")
    .addConditionalEdges("generateQueryOrRespond", shouldRetrieve)
    .addConditionalEdges("retrieve", gradeDocuments)
    .addEdge("generate", END)
    .addEdge("rewrite", "generateQueryOrRespond")
    .compile();
```

四个节点:

1.`generateQueryOrRespond`: 分析问题, 决定直接回答还是调用检索Tool

2.`retrieve`: 执行检索Tool, 从向量库获取文档

3.`gradeDocuments`: 对检索出的文档进行打分, 判断文档和问题是否相关

   - 如果相关, 跳转到`generate`生成答案

   - 如果不相关, 跳转到`rewrite`重写问题并重试

4.`rewrite`: 检索结果不相关时, 修改问题

   修改完后跳转到`generateQueryOrRespond`

5.`generate`: 根据相关文档生成最终答案
