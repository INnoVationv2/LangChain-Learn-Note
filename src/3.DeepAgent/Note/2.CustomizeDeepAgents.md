# 2.自定义Deep Agents

`createDeepAgent()` 默认预装`filesystem`、`summarization`、`subagent`和`prompt caching`组件，

可通过以下参数自定义Agent, 扩展Deep Agent的技术栈.

```st
const agent = createDeepAgent({
  model: "openai:gpt-5.5",
  systemPrompt: "你是一个乐于助人的助手。",
  tools: [search, fetchUrl], // 已定义的工具
  memory: ["./AGENTS.md"],
  skills: ["./skills/"],
});
```

| 参数             | 作用                                                |
| ---------------- | --------------------------------------------------- |
| `model`          | 指定模型                                            |
| `systemPrompt`   | 自定义系统指令                                      |
| `tools`          | 添加业务工具                                        |
| `memory`         | 启动时加载的指令文件                                |
| `skills`         | 按需加载的技能目录                                  |
| `backend`        | 文件存储后端，默认 `StateBackend`                   |
| `permissions`    | 文件路径级访问控制                                  |
| `subagents`      | 自定义子代理                                        |
| `middleware`     | 添加中间件                                          |
| `interruptOn`    | 指定哪些工具调用需要人工审批                        |
| `responseFormat` | 定义结构化输出                                      |
| `contextSchema`  | 定义每次运行的上下文，如用户 ID、API 密钥、功能开关 |

## 1.Model

`model` 接受 `provider:model` 字符串，也接受已初始化的模型实例。

三种配置方式：

```ts
import { createDeepAgent } from "deepagents";
import { initChatModel } from "langchain";
import { ChatOpenAI } from "@langchain/openai";

// 1. 字符串：使用默认模型配置
const agent1 = createDeepAgent({ model: "openai:gpt-5.5" });

// 2. 通用初始化函数：配置模型参数
const model = await initChatModel("openai:gpt-5.5", { temperature: 0 });
const agent2 = createDeepAgent({ model });

// 3. 模型类：直接配置提供商参数
const agent3 = createDeepAgent({
  model: new ChatOpenAI({ model: "gpt-5.5", temperature: 0 }),
});
```

API 密钥通过环境变量配置；

Model通常会对临时错误进行指数退避重试; 重试次数和超时通过模型配置调整。

## 2.Tool

内置了文件操作、子代理调用工具，也可以自定义工具。

### MCP 工具

通过 MCP 可以接入数据库、API、文件系统等服务提供的工具。

```ts
npm install @langchain/mcp-adapters
import { MultiServerMCPClient } from "@langchain/mcp-adapters";

const client = new MultiServerMCPClient({
  my_server: {
    transport: "http",
    url: "http://localhost:8000/mcp",
  },
});

const agent = createDeepAgent({
  model: "openai:gpt-5.5",
  tools: await client.getTools(),
});

const result = await agent.invoke({
  messages: [{ role: "user", content: "使用 MCP 服务帮助我。" }],
});
```

还支持 stdio、OAuth、工具过滤和有状态会话等配置。

## 3.System Prompt

通过 `systemPrompt` 定义角色、目标和行为要求。

```
const agent = createDeepAgent({
  model: "openai:gpt-5.5",
  systemPrompt: "你是一名研究员。充分调查问题，然后撰写清晰的研究报告。",
});
```

**子代理提示词**

子代理根据自己的模型解析 harness profile：

- `system_prompt_suffix`：追加到编写的提示词后。
- `base_system_prompt`：替换编写的提示词。

例如，子 Agent 原提示词是 `"你是一名代码审查员。"`：

```
system_prompt_suffix = "请用中文回答。"
→ 你是一名代码审查员。请用中文回答。

同时设置base_system_prompt = "你是一名安全审查员。"
→ 你是一名安全审查员。请用中文回答。
```

提示词的优先级为：

```
general_purpose_subagent.system_prompt
→ HarnessProfile.base_system_prompt
→ SDK 默认提示词
```

选定基础提示词后，再追加 profile 的后缀。

```python
from deepagents import (
    GeneralPurposeSubagentProfile,
    HarnessProfile,
    register_harness_profile,
)

register_harness_profile(
    "anthropic",
    HarnessProfile(
        base_system_prompt="你是 ACME 的客服协调员。",
        general_purpose_subagent=GeneralPurposeSubagentProfile(
            system_prompt="你是研究子代理，需要注明来源。",
        ),
        system_prompt_suffix="请逐步思考。",
    ),
)
```

| Agent        | 最终prompt                                     |
| ------------ | ---------------------------------------------- |
| 主 Agent     | 你是 ACME 的客服协调员。请逐步思考。           |
| 通用子 Agent | 你是一名研究子 Agent，请注明来源。请逐步思考。 |

## 4.Middleware

通过 `middleware` 参数添加，

自定义的中间件会附加到 `PatchToolCallsMiddleware` 之后。

### Deep Agents 中间件栈

中间件按固定顺序组装

1. **最小栈**

1. 只传入模型时，主 Agent 通常包含：

   | 中间件                     | 作用                                             |
   | -------------------------- | ------------------------------------------------ |
   | `FilesystemMiddleware`     | 提供文件读写、目录操作等能力                     |
   | `SubAgentMiddleware`       | 提供子 Agent 委派能力，默认自动加入通用子 Agent  |
   | `SummarizationMiddleware`  | 压缩历史消息，避免超出上下文限制                 |
   | `PatchToolCallsMiddleware` | 修复消息历史中未配对的工具调用等异常             |
   | 模型相关中间件             | 根据模型配置，添加额外处理、工具过滤和提示词缓存 |

2. **完整栈**

   1. **Skill Middleware**：传入Skill时启用.

   2. **Filesystem Middleware**：提供文件操作；传入 `permissions` 时，也在这一步实施文件系统权限检查

   3. **SubAgentMiddleware**：至少有一个子Agent时启用；负责委派任务

   4. **SummarizationMiddleware**：压缩过长的消息历史

   5. **PatchToolCallsMiddleware**：修复中断恢复或工具调用参数异常造成的消息问题

   6. **AsyncSubAgentMiddleware**：仅当您配置异步子代理时才需要。

   7. **自定义 `middleware`**：用户传入的中间件

   8. **模型配置附加中间件**：加入 harness profile 定义的提供商专用处理

   9. **排除工具过滤**：移除 harness profile 禁用的工具

   10. **提示词缓存中间件**：为 Anthropic 和 Amazon Bedrock Converse 模型自动加入对应缓存处理

   11. **MemoryMiddleware**：传入 `memory` 时启用；注入记忆内容

       `MemoryMiddleware`放置在`profile extras`和`prompt caching middleware`之后，为了让 Memory 的变化尽量不要导致缓存失效。

   12. **HumanInTheLoopMiddleware**：传入 `interruptOn` 时启用；在指定工具调用处暂停，等待人工处理.

Memory 放在缓存中间件之后，以降低记忆更新使缓存前缀失效的可能性。

禁用默认通用子代理且不提供其他同步子代理时，可以去掉同步子代理中间件。

### 同步子代理栈

通用子代理和声明式同步子代理的中间件结构与主代理相似，但有两点区别：

- 技能中间件位于 `PatchToolCallsMiddleware` 之后。
- 内部没有 `SubAgentMiddleware`，只有父代理暴露 `task` 工具。

子代理的 `interruptOn` 会传给内部 `createAgent()`，配置对应的人工审批。

**内置中间件**

LangChain 提供重试、模型回退、个人敏感信息检测等中间件。

Deep Agents 也导出 `createSummarizationMiddleware()`，用于配置摘要能力。

**自定义中间件**

可以添加工具、实现钩子，或拦截模型和工具调用。

跨钩子保存计数等数据时，应更新图状态，避免修改共享变量或直接修改 `state`，否则并行工具、子代理和多线程调用可能相互影响。

```ts
// 示意：x 需要在状态 schema 中声明
const good = createMiddleware({
  name: "Good",
  beforeAgent: async (state) => ({ x: (state.x ?? 0) + 1 }),
});
// 不推荐：不同调用共享 x
let x = 1;

const bad = createMiddleware({
  name: "Bad",
  beforeAgent: async () => { x += 1; },
});
```

### 解释器

解释器中间件提供 `eval` 工具，在受限的 QuickJS 运行时执行 JavaScript。

适合用代码组合工具、批量处理、捕获错误和转换结构化数据，无需完整 Shell 环境。

```ts
import { createCodeInterpreterMiddleware } from "@langchain/quickjs";

const agent = createDeepAgent({
  model: "openai:gpt-5.5",
  middleware: [createCodeInterpreterMiddleware()],
});
```

## 5.subagent

把细节较多的工作交给子代理，隔离上下文，减少主代理的上下文膨胀。

```ts
import { type SubAgent } from "deepagents";

const researcher: SubAgent = {
  name: "research-agent",
  description: "处理需要深入研究的问题",
  systemPrompt: "你是一名研究员。",
  tools: [internetSearch],
  model: "openai:gpt-5.5", // 可选；默认使用主代理模型
};

const agent = createDeepAgent({
  model: "openai:gpt-5.5",
  subagents: [researcher],
});
```

## 6.后端

后端决定文件如何存储和访问，默认使用 `StateBackend`。

使用 Skills 或 Memory 时，需要准备相应文件，让后端在加载时能够读取。

| 后端                | 存储位置与用途                                               |
| ------------------- | ------------------------------------------------------------ |
| `StateBackend`      | 文件保存在图状态中；配合 checkpointer 在同一线程内保留，不跨线程共享 |
| `FilesystemBackend` | 直接读写本机文件                                             |
| `LocalShellBackend` | 本机文件操作，并提供执行命令的 `execute` 工具                |
| `StoreBackend`      | 通过 Store 跨线程保存文件                                    |
| `ContextHubBackend` | 将文件持久化到 LangSmith Hub 仓库                            |
| `CompositeBackend`  | 按路径把文件操作分配给不同后端                               |

**StateBackend**

```ts
import { StateBackend } from "deepagents";

const agent1 = createDeepAgent();
const agent2 = createDeepAgent({ backend: new StateBackend() });
```

**FilesystemBackend**

```ts
import { FilesystemBackend } from "deepagents";

const agent = createDeepAgent({
  backend: new FilesystemBackend({ rootDir: ".", virtualMode: true }),
});
```

这会直接读写本机文件。可以用 `CompositeBackend` 分离项目文件和代理内部数据，避免卸载的工具结果、历史记录混入项目目录。

**LocalShellBackend**

```ts
import { LocalShellBackend } from "deepagents";

const agent = createDeepAgent({
  backend: new LocalShellBackend({ workingDirectory: "." }),
});
```

它还允许在宿主机执行 Shell 命令，需要谨慎选择运行环境。

**StoreBackend**

```ts
import { StoreBackend } from "deepagents";
import { InMemoryStore } from "@langchain/langgraph";

const agent = createDeepAgent({
  backend: new StoreBackend({
    namespace: (rt) => [rt.serverInfo.user.identity],
  }),
  store: new InMemoryStore(),
});
```

`namespace` 用于隔离不同用户或租户的数据。`InMemoryStore` 适合本地开发；部署到 LangSmith Deployment 时可省略 `store`，由平台提供。

**ContextHubBackend**

使用 LangSmith Hub 仓库进行持久化文件存储，原文没有代码示例。

**CompositeBackend**

```ts
import { CompositeBackend, StateBackend, StoreBackend } from "deepagents";

const agent = createDeepAgent({
  backend: new CompositeBackend(new StateBackend(), {
    "/memories/": new StoreBackend({ namespace: () => ["memories"] }),
  }),
  store: new InMemoryStore(),
});
```

普通路径使用线程状态；`/memories/` 路径使用跨线程存储。

### 沙箱

沙箱后端提供隔离的文件系统和 `execute` 工具，可以写文件、安装依赖、运行命令，避免直接修改本机环境。

```ts
import { LangSmithSandbox } from "deepagents";
import { SandboxClient } from "langsmith/sandbox";

const client = new SandboxClient();
const sandbox = await client.createSandbox();

try {
  const agent = createDeepAgent({
    model: "openai:gpt-5.5",
    backend: new LangSmithSandbox({ sandbox }),
  });

  await agent.invoke({
    messages: [{ role: "user", content: "创建并运行一个 Python Hello World。" }],
  });
} finally {
  await client.deleteSandbox(sandbox.name);
}
```

## 7.人工介入

通过 `interruptOn` 控制工具执行前是否暂停审批，**必须配置 checkpointer**。

```ts
import { MemorySaver } from "@langchain/langgraph";

const removeFile = tool(({ path }) => `Deleted ${path}`, {
  name: "remove_file",
  description: "删除文件",
  schema: z.object({ path: z.string() }),
});

const fetchFile = tool(({ path }) => `Contents of ${path}`, {
  name: "fetch_file",
  description: "读取文件",
  schema: z.object({ path: z.string() }),
});

const notifyEmail = tool(({ to }) => `Sent email to ${to}`, {
  name: "notify_email",
  description: "发送邮件",
  schema: z.object({ to: z.string(), subject: z.string(), body: z.string() }),
});

const agent = createDeepAgent({
  tools: [removeFile, fetchFile, notifyEmail],
  interruptOn: {
    remove_file: true,
    fetch_file: false,
    notify_email: { allowedDecisions: ["approve", "reject"] },
  },
  checkpointer: new MemorySaver(),
});
```

以上工具只返回模拟结果。

- `true`：启用审批，原文列出 `approve`、`edit`、`reject`、`respond`。
- `false`：不暂停。
- `allowedDecisions`：限制可选操作。

主代理、子代理都可以配置工具调用中断，也可以在工具内部触发中断。

## 8.Skill

Skill提供任务说明、专业知识、参考资料和模板；Tools 提供具体操作能力。

Skill内容按需读取，减少启动时占用的上下文。`skills` 指向后端中的目录，使用相对于后端根目录的虚拟 POSIX 路径。

**准备技能内容**

```ts
const skillUrl =
  "https://raw.githubusercontent.com/langchain-ai/deepagentsjs/refs/heads/main/examples/skills/langgraph-docs/SKILL.md";
const skillContent = await (await fetch(skillUrl)).text();
const skillPath = "/skills/langgraph-docs/SKILL.md";
const config = { configurable: { thread_id: "skills-demo" } };
const messages = [{ role: "user", content: "什么是 LangGraph？" }];
```

**StateBackend：调用时传入文件**

```ts
const now = new Date().toISOString();

const agent = createDeepAgent({
  backend: new StateBackend(),
  skills: ["/skills/"],
  checkpointer: new MemorySaver(),
});

await agent.invoke({
  messages,
  files: {
    [skillPath]: {
      content: skillContent.split("\n"),
      created_at: now,
      modified_at: now,
    },
  },
}, config);
```

**StoreBackend：先上传文件**

```ts
const store = new InMemoryStore();
const backend = new StoreBackend({
  namespace: () => ["filesystem"],
  store,
});

await backend.uploadFiles([
  [skillPath, new TextEncoder().encode(skillContent)],
]);

const agent = createDeepAgent({
  backend,
  store,
  skills: ["/skills/"],
  checkpointer: new MemorySaver(),
});

await agent.invoke({ messages }, { ...config, recursionLimit: 50 });
```

**FilesystemBackend：写入本机目录**

```
const backend = new FilesystemBackend({
  rootDir: process.cwd(),
  virtualMode: true,
});

await backend.uploadFiles([
  [skillPath, new TextEncoder().encode(skillContent)],
]);

const agent = createDeepAgent({
  backend,
  skills: ["/skills/"],
  interruptOn: { read_file: true, write_file: true, delete_file: true },
  checkpointer: new MemorySaver(),
});

await agent.invoke({ messages }, config);
```

此示例配置了人工审批，因此需要 checkpointer。

## 9.Memory

通过 `memory` 指定一个或多个 `AGENTS.md` 文件，为代理提供额外上下文。OpenWiki 也可以生成供代理通过 `AGENTS.md` 发现的仓库知识。

原文同样演示三种后端。

**准备记忆内容**

```
const url =
  "https://raw.githubusercontent.com/langchain-ai/deepagents/refs/heads/main/examples/text-to-sql-agent/AGENTS.md";
const response = await fetch(url);
if (!response.ok) throw new Error(`加载失败：${response.status}`);

const content = await response.text();
const now = new Date().toISOString();
const fileData = {
  content,
  mimeType: "text/plain",
  created_at: now,
  modified_at: now,
};
const config = { configurable: { thread_id: "memory-demo" } };
const messages = [{ role: "user", content: "介绍你的记忆文件。" }];
```

**StateBackend：通过状态注入**

```
const agent = createDeepAgent({
  memory: ["/AGENTS.md"],
  checkpointer: new MemorySaver(),
});

await agent.invoke({
  messages,
  files: { "/AGENTS.md": fileData },
}, config);
```

**StoreBackend：先写入 Store**

```
const store = new InMemoryStore();
await store.put(["filesystem"], "/AGENTS.md", fileData);

const agent = createDeepAgent({
  backend: new StoreBackend({ namespace: () => ["filesystem"] }),
  store,
  memory: ["/AGENTS.md"],
  checkpointer: new MemorySaver(),
});

await agent.invoke({ messages }, config);
```

**FilesystemBackend：读取现有文件**

```ts
const agent = createDeepAgent({
  backend: new FilesystemBackend({ rootDir: "/path/to/project" }),
  memory: ["./AGENTS.md", "./.deepagents/AGENTS.md"],
  interruptOn: { read_file: true, write_file: true, delete_file: true },
  checkpointer: new MemorySaver(),
});
```

原文 Skills 与 Memory 示例的 `FileData.content` 分别采用数组和字符串两种格式；实际使用时应以安装版本的类型定义为准。

## 10.结构化输出

通过 `responseFormat` 定义输出结构，框架捕获并验证结果，保存在 `result.structuredResponse` 中。

```ts
const weatherSchema = z.object({
  location: z.string().describe("地点"),
  temperature: z.number().describe("温度，摄氏度"),
  condition: z.string().describe("天气状况"),
  humidity: z.number().describe("湿度百分比"),
  windSpeed: z.number().describe("风速，千米/小时"),
  forecast: z.string().describe("未来 24 小时预报"),
});

const agent = createDeepAgent({
  tools: [internetSearch],
  responseFormat: weatherSchema,
});
```
