# 人工审批

## 1.基本配置

-`interrupt_on`用来设置哪些工具需要暂停执行、等待人工审核，以及审核时允许哪些操作。有以下参数:
  - **`True`**：开启人工审核，允许批准、编辑或拒绝。
  - **`False`**：关闭人工审核。
  - **`InterruptOnConfig`**：自定义审核规则，通过`allowed_decisions`指定允许的审核操作。

## 2.Decision 类型

`allowed_decisions`控制人工审核时，可以选择哪些操作：

| 操作      | 说明                                         |
| --------- | -------------------------------------------- |
|`approve`| 按Agent提供的参数继续执行                   |
|`edit`| 修改参数后再执行                             |
|`reject`| 不执行此次工具调用，并将拒绝原因反馈给Agent |

> **修改工具参数时，尽量只做必要的小幅调整: ** 大幅修改可能会让模型重新考虑执行方案，导致重复调用工具或采取意料之外的操作。

可以为每个工具单独设置Decision。

```ts
const interruptOn = {
  // Sensitive operations: allow all options
  delete_file: { allowedDecisions: ["approve", "edit", "reject"] },

  // Moderate risk: approval or rejection only
  write_file: { allowedDecisions: ["approve", "reject"] },

  // Must approve (no rejection allowed)
  critical_operation: { allowedDecisions: ["approve"] },
};
```

## 3.处理中断

触发中断时，Agent会暂停执行并交回控制权。此时需要检查返回的中断信息，进行相应处理。

如果用户拒绝执行某个操作，应明确告知Agent：工具未执行以及接下来该做什么。

## 4.在Streaming中处理中断

对于实时用户界面，用`.stream()`代替`.invoke()`，可以一边显示模型生成的文字和工具调用进度，一边处理人工审核中断(HITL)。

中断信息会以`__interrupt__`的形式出现在`updates`流中。流结束后，收集人工审核决定，再通过`Command(resume=...)`重新启动流式执行。

> 对于常见的`interrupt_on`，恢复时传入以下结构，与`.invoke()`用法相同：
>
> ```ts
> {"decisions": [...]}
> ```
>
> 如果有多个中断等待处理，则将每个中断ID映射到其恢复值.

通常, 一个中断里, 包含多个待审批的工具调用。例如：

```ts
const interrupts = [{
    id: "interrupt-1",
    value: {
        actionRequests: [
            { name: "get_weather", args: { city: "NY" } },
            { name: "send_email", args: { to: "a@example.com" } },
        ],
    },
}];
```

虽然有两个工具调用，但只有**一个中断**。按**工具调用顺序**提供两个决定即可：

```ts
  const decisions = [
    { type: "approve" },
    {
      type: "reject",
      message: "User rejected this action. Do not retry this tool call.",
    },
  ];

  result = await agent.invoke( new Command({resume:{decisions}}), config);
```

如果存在**多个独立中断**，则需要用ID指明decisions属于哪个中断：

```ts
streamInput = new Command({
    resume: {
        "interrupt-1": {
            decisions: [{ type: "approve" }],
        },
        "interrupt-2": {
            decisions: [{ type: "reject", message: "取消操作" }],
        },
    },
});
```

[代码](https://github.com/INnoVationv2/LangChain-Learn-Note/blob/main/src/3.DeepAgent/Code/5.HumanInTheLoop.test.ts#L88)

同时使用`"messages"`和`"updates"`两种流模式，可以兼顾实时文字展示和中断处理：

-`messages`：实时输出模型生成的文字。
-`updates`：传递中断信息。

## 5.Reject

选择`reject`后，Deep Agents 会跳过该工具调用，并将Reject反馈发送给Agent。

如果没有提供`message`，默认会告诉模型：工具没有执行，除非用户要求，否则不要重试同一次工具调用。

应通过`message`提供符合具体业务场景的说明，明确告诉Agent接下来应该：

- 放弃该操作；
- 向用户进一步确认；
- 尝试更安全的替代方案。

## 6.修改工具参数

可以在工具执行前修改参数。

```ts
const decisions = [
            {
                type: 'edit',
                editedAction: {
                    // 修改成其他Tool, 会调用新Tool
                    name: getRainingWeather.name,
                    args: {city: 'Peking'},
                }
            }
        ];
```

## 7.SubAgent中断

使用SubAgent时，可以在**调用工具前**触发中断，也可以在**工具执行过程中**触发中断。

### 1.调用工具前中断

SubAgent可以单独设置`interrupt_on`，覆盖主Agent的配置。

```ts
const agent = createDeepAgent({
  tools: [deleteFile, readFile],
  interruptOn: {
    delete_file: true,
    read_file: false,
  },
  subagents: [{
    name: "file-manager",
    description: "Manages file operations",
    systemPrompt: "You are a file management assistant.",
    tools: [deleteFile, readFile],
    interruptOn: {
      delete_file: true,
      read_file: true,
    }
  }],
  checkpointer
});
```

SubAgent触发中断后，处理方式相同：检查返回结果中的`__interrupt__`，再通过`Command`恢复执行。

在流式输出中，SubAgent的中断也会以`__interrupt__`条目的形式出现在父Agent的`updates`流中，无需设置`subgraphs=True`。

如果还想实时获取SubAgent生成的文字和执行进度，则需要开启`subgraphs=True`。

### 2.工具执行过程中中断

SubAgent的Tool可以直接调用`interrupt()`，暂停执行并等待人工批准。

```ts
import { createAgent, tool } from "langchain";
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage } from "@langchain/core/messages";
import { MemorySaver, Command, interrupt } from "@langchain/langgraph";
import { createDeepAgent } from "deepagents";
import { z } from "zod";

const requestApproval = tool(
  async ({ actionDescription }: { actionDescription: string }) => {
    const approval = interrupt({
      type: "approval_request",
      action: actionDescription,
      message: `Please approve or reject: ${actionDescription}`,
    }) as { approved?: boolean; reason?: string };

    if (approval.approved) {
      return `Action '${actionDescription}' was APPROVED. Proceeding...`;
    } else {
      return `Action '${actionDescription}' was REJECTED. Reason: ${
        approval.reason || "No reason provided"
      }`;
    }
  },
  {
    name: "request_approval",
    description: "Request human approval before proceeding with an action.",
    schema: z.object({
      actionDescription: z
        .string()
        .describe("The action that requires approval"),
    }),
  }
);

async function main() {
  const checkpointer = new MemorySaver();
  const model = new ChatOpenAI({
    model: "gpt-5.4-mini",
    maxTokens: 4096,
  });

  const compiledSubagent = createAgent({
    model: model,
    tools: [requestApproval],
    name: "approval-agent",
  });

  const parentAgent = await createDeepAgent({
    checkpointer: checkpointer,
    subagents: [
      {
        name: "approval-agent",
        description: "An agent that can request approvals",
        runnable: compiledSubagent as any,
      },
    ],
  });

  const threadId = "test_interrupt_directly";
  const config = { configurable: { thread_id: threadId } };

  console.log("Invoking agent - sub-agent will use request_approval tool...");

  let result = await parentAgent.invoke(
    {
      messages: [
        new HumanMessage({
          content:
            "Use the task tool to launch the approval-agent sub-agent. " +
            "Tell it to use the request_approval tool to request approval for 'deploying to production'.",
        }),
      ],
    },
    config
  );

  if (result.__interrupt__) {
    const interruptValue = result.__interrupt__[0].value as {
      type?: string;
      action?: string;
      message?: string;
    };
    console.log("\nInterrupt received!");
    console.log(`  Type: ${interruptValue.type}`);
    console.log(`  Action: ${interruptValue.action}`);
    console.log(`  Message: ${interruptValue.message}`);

    console.log("\nResuming with Command(resume={'approved': true})...");
    const result2 = await parentAgent.invoke(
      new Command({ resume: { approved: true } }),
      config
    );

    if (!result2.__interrupt__) {
      console.log("\nExecution completed!");
      // Find the tool response
      const toolMsgs = result2.messages?.filter((m) => m.type === "tool") || [];
      if (toolMsgs.length > 0) {
        const lastToolMsg = toolMsgs[toolMsgs.length - 1];
        console.log(`  Tool result: ${lastToolMsg.content}`);
      }
    } else {
      console.log("\nAnother interrupt occurred");
    }
  } else {
    console.log(
      "\n  No interrupt - the model may not have called request_approval"
    );
  }
}

main().catch(console.error);
```
