Deep Agents 是一套**带配套能力的 Agent 框架（Agent Harness）**：在模型调用工具的循环之外，提供文件管理、上下文压缩、记忆、子Agnet和人工审批。底层使用 LangChain 和 LangGraph。

# 1.核心能力

<img src="http://pic-save-fury.oss-cn-shanghai.aliyuncs.com/uPic/agent_harness_capabilities.svg" alt="按类别划分的Agnet工具功能" style="zoom:50%;" />

Deep Agents 是一个`Agnet框架(agent harness)`。与其他Agnet框架使用相同的核心，但内置了一些功能，使Agnet能够可靠地执行实际任务：

1. [执行环境](#执行环境): 工具、虚拟文件系统、可选沙箱和 REPL（解释器）
2. Context管理: Skill、Memory、摘要、Context卸载和Prompt缓存
3. 托管: 子Agnet生成和可选任务规划
4. 人机交互审批和中断

## 1. 执行环境

由四层组成：

- **工具（Tools）**：Agnet可调用的自定义函数、API 和数据库。
- **虚拟文件系统**：提供文件操作工具，支持替换底层存储后端。
- **文件系统权限**：通过声明式规则，控制Agnet可读取或写入的路径。
- **代码执行**：支持在沙箱中执行 Shell 命令，以及在当前进程内运行 JavaScript 解释器。

### 1.工具和MCP

可以使用 ` tools = ` 参数传递自定义函数、LangChain 工具或MCP服务器的工具。

### 2. 虚拟文件系统

框架提供一个可配置的虚拟文件系统，由不同的可插拔后端提供支持：内存状态、本地磁盘、LangGraph 存储、复合路由，或者具有读写访问权限规则的自定义后端.

支持以下文件操作：

| 工具         | 功能                                                         |
| ------------ | ------------------------------------------------------------ |
| `ls`         | 列出目录中的文件及元数据，如大小、修改时间                   |
| `read_file`  | 读取文件内容并显示行号，支持通过 `offset` / `limit` 分段读取大文件；也支持将图片、视频、音频和文档等非文本文件返回为多模态内容块 |
| `write_file` | 创建新文件                                                   |
| `edit_file`  | 精确替换文件中的字符串，支持全局替换                         |
| `glob`       | 按模式查找文件，如 `**/*.py`                                 |
| `grep`       | 搜索文件内容，支持仅返回文件名、返回匹配内容及上下文，或返回匹配数量 |
| `execute`    | 在环境中执行 Shell 命令，仅沙箱后端支持                      |

### 3.文件系统权限

框架支持声明式权限规则，控制可以读写哪些文件和目录。规则适用于前面列出的内置文件系统工具。

创建Agnet时，通过 `permissions` 传入规则列表，每条规则包含：

| 字段         | 含义                                 |
| ------------ | ------------------------------------ |
| `operations` | `"read"`、`"write"`，或两者          |
| `paths`      | 匹配文件或目录的 Glob 模式           |
| `mode`       | `"allow"`（允许）或 `"deny"`（拒绝） |

规则**从上到下匹配，第一条匹配的规则生效；没有匹配规则时，默认允许操作**。

可以用它限制Agnet只访问指定目录（如 `/workspace/`）、保护 `.env` 和凭据文件，或让子Agnet拥有比父Agnet更小的访问范围。

权限限制不适用于沙盒后端，沙盒后端支持通过execute工具执行任意命令。如需自定义验证逻辑，请使用后端策略钩子。

### 4. 代码执行

支持两种代码执行方式：

- 沙箱后端: 提供一个在隔离环境中执行shell 命令的工具.:

  适用于需要安装依赖项、运行测试、调用命令行界面 (CLI) 或操作文件系统时。

  沙箱后端实现了SandboxBackendProtocolV2协议；检测到沙箱后端后，该框架会将`execute`工具添加到工具列表中。

- 解释器: 提供一个eval工具，可在限定作用域的 QuickJS 运行时中运行 JavaScript

  适用于需要一个轻量级的编程能力进行循环、批处理、确定性数据转换或程序化工具调用时。不提供 shell 访问、软件包安装, 访问文件系统或网络的能力。

## 2.Context管理

- **Skill**：按需从技能文件中逐步加载的领域知识
- **Memory**：启动时从AGENTS.md文件加载的持久性指令和首选项
- **摘要和上下文卸载**：自动压缩对话历史记录和大型工具结果
- **prompt-caching**：静态提示部分可以缓存，以加快推理速度并降低所支持模型的成本

### 1. Skill

每个技能都遵循[Agnet技能标准](https://agentskills.io/home)，存储在包含SKILL.md文件的目录中。技能还可以包含脚本、模板、参考文档和其他辅助资源。

Deep Agent采用懒加载技能的方式：启动时读取`SKILL.md`的前言，仅在任务需要时才读取完整的技能内容。

### 2.Memory

Memory使Deep Agent能在对话中保持上下文的持久性，例如编码风格、偏好、惯例和项目指南。

内存使用[AGENTS.md]((https://agents.md/))文件，在创建Agnet时通过`memory`参数传递。与技能不同，该文件始终会被加载，其内容存储在配置的后端（StateBackend、StoreBackend或FilesystemBackend）中。

还可以根据交互和反馈进行更新，因此偏好可以延续下去，无需在开启新对话时重新表达。

### 3. 摘要和上下文卸载

管理上下文，以便能够在`token limits`内处理长时间运行的工作，同时将相关信息保留在范围内。包含四个部分：

- **Input Context**：系统提示、内存、技能和工具提示定义了Agnet的初始状态。
- **压缩**：内置的卸载和摘要功能可压缩对话历史记录和大型中间结果。
- **隔离**：耗时较长的子任务委托给子Agnet，只返回最终结果。
- **长期记忆**：虚拟文件系统中的持久存储可在线程间传递信息。

这些机制共同支持跨越单个上下文窗口的多步骤任务，减少手动上下文修剪和令牌使用。

### 4.prompt-caching

对于 Anthropic 和 Amazon Bedrock，`create_deep_agent` 会自动缓存系统提示词中的静态部分，包括每轮重复使用的基础指令、记忆和技能内容，避免在多次调用中重复处理相同的 token，降低长时间运行的Agnet的延迟和成本。

使用 Anthropic 模型或 Bedrock 模型（Claude、Nova）时，提示词缓存默认开启，无需配置。

其他模型提供商可使用对应的缓存中间件。

## 3.委托

把大问题拆成可并行执行的小任务，包含两层：

- **任务规划**：按需启用 `write_todos` 工具，维护任务列表。
- **子Agnet**：创建临时子Agnet，处理独立子任务。

### **1.任务规划**

需要显式启用, 适用于：

- 耗时较长、步骤较多的复杂任务。
- 能力较弱、需要明确任务清单辅助执行的模型。
- 从Agnet状态中流式展示任务进度的界面。

通过 `middleware` 添加 `todoListMiddleware()`，为Agnet提供 `write_todos` 工具：

```ts
import { createDeepAgent } from "deepagents";
import { todoListMiddleware } from "langchain";

const agent = await createDeepAgent({
  model: "openai:gpt-5.5",
  middleware: [todoListMiddleware()],
});
```

任务列表保存在Agnet状态中，支持三种状态：

| 状态          | 含义   |
| ------------- | ------ |
| `pending`     | 待处理 |
| `in_progress` | 进行中 |
| `completed`   | 已完成 |

### **2.子Agnet**

内置 `task` 工具，创建临时子Agnet，处理独立、耗时、多步骤或可并行的任务。

- **全新上下文**：每次调用都会创建一个新的上下文的Agent。
- **自主执行**：独立运行直到完成。
- **一次性汇报**：只向主Agnet返回一份最终报告，不支持多次回传消息。
- **可配置**：默认启用通用子Agnet，可自定义子Agnet。
- **无状态**：子Agent是无状态的，不能发送多条消息。
- **节省上下文和 token**：复杂子任务在子Agent处理，只返回精简结果。

## 4.人工审批

使用户能够在运行时控制Agnet的行为，为Agnet工作设置文件系统权限。

Deep Agents集成 LangGraph 中断机制，可在敏感工具执行前暂停，等待人工审批。通过 `create_deep_agent` 的 `interrupt_on` 参数启用，

例如，`interrupt_on={"edit_file": True}` 表示每次编辑文件前暂停，让用户批准调用、补充指导或修改工具参数。
