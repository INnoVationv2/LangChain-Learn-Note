# 沙盒

**Agent 会操作文件、生成代码、运行命令, 需要把它放在与宿主系统隔离的环境里, 防止访问敏感资源.**

Deep Agents中, 沙箱是一种**Backend(Backend)**, 负责提供Agent的运行环境：

| Backend                     | 提供的能力                                |
| ------------------------ | ----------------------------------------- |
| State、Filesystem、Store | 文件操作                                  |
| Sandbox                  | 文件操作 + 通过`execute`运行 Shell 命令 |

配置沙箱后, Agent 可以在沙箱内部读写文件、运行命令；沙箱的隔离边界用来保护宿主系统中的文件、凭据和网络资源.
