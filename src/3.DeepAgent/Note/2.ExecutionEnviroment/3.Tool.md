## 3.Harness内置工具

Deep Agent自带以下工具：

| 工具         | 作用                           |
| ------------ | ------------------------------ |
| `ls`         | 列出目录中的文件               |
| `read_file`  | 读取文件，支持分页和多模态内容 |
| `write_file` | 创建新文件                     |
| `edit_file`  | 精确匹配并替换文件中的字符串   |
| `glob`       | 按文件名或路径模式查找文件     |
| `grep`       | 搜索文件内容                   |
| `execute`    | 执行 Shell 命令，仅限沙箱后端  |
| `task`       | 启动子 Agent，执行委派任务     |

需要通过 `write_todos` 管理结构化任务清单时，必须主动添加 `todoListMiddleware`，默认不包含：

```ts
import { createDeepAgent } from "deepagents";
import { todoListMiddleware } from "langchain";

const agent = createDeepAgent({
  middleware: [todoListMiddleware()],
});
```

## 4.多模态工具输出

工具也可以返回多模态内容。例如, 读取一张图片后，可以同时返回说明文字和图片：

```ts
// 工具执行函数的返回值
return [
  { type: "text", text: "这是需要分析的界面截图。" },
  { type: "image", url: "https://example.com/screenshot.png" },
];
```

内容按数组顺序组织，让模型同时获得文字说明和媒体内容。
