## 1.Memory工作原理

1. **指定Memory文件**
   - 创建 Agent 时，通过 `memory` 传入记忆文件路径。
   - 通过 `skills` 传入可复用的任务操作指南，作为**程序性记忆**，告诉 Agent 如何执行任务。
   - `backend` 决定文件存储位置和访问权限。
2. **读取Memory**
   - 记忆文件可以在启动时加载到系统提示词，也可以在对话中按需读取。
   - 例如 Skills：启动时只加载技能描述，任务需要时才读取完整文件，减少上下文占用。
3. **更新Memory（可选）**
   - Agent 学到新信息后，可通过`edit_file`工具更新Memory。
   - 默认在对话中更新，也可以通过**后台整合**，在对话之间更新。
   - 修改会持久保存，供后续对话使用。
   - 并非所有记忆都可修改：开发者定义的 Skills 和组织策略通常只读。

常见的Memory作用域：Agent级Memory(所有用户共享) 和 用户级Memory(按用户隔离)
